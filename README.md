# 🎬 Netflix Data Analysis Dashboard

🚀 A data-driven dashboard that uncovers insights from Netflix’s global content library using interactive visualizations.

---

## 📊 Project Overview

This project analyzes Netflix titles to identify trends in:
- Content growth over time
- Distribution of Movies vs TV Shows
- Popular genres and categories
- Country-wise content availability
- Content ratings and audience targeting

The goal is to transform raw data into meaningful insights using visual analytics.

## 🔍 Key Insights

✔️ Netflix has **8,800+ titles** across **7,900+ countries**  
✔️ **Movies dominate** the platform over TV Shows  
✔️ Significant growth in content after 2015  
✔️ Popular categories include *Drama, International Movies, Kids TV*  
✔️ Majority of content falls under **TV-MA and TV-14 ratings**
